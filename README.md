# Amazon Sales Dashboard

An interactive **Amazon Sales Dashboard** built using Excel to analyze sales, profit, products, categories, order status, payment methods, fulfillment, and geographical performance.

## 📊 Project Overview

This project transforms Amazon sales data into clear, interactive dashboards and analysis sheets. It helps identify sales trends, profitable categories, order issues, revenue loss, and regional performance.

## 📁 Workbook Structure

The project contains 5 Excel files:

1. **Dashboard.xlsx**
   Main Amazon Sales Dashboard with key KPIs and visualizations.

2. **Objective 1 — Sales & Profit.xlsx**
   Analysis of sales, revenue, profit, and overall performance.

3. **Objective 2 — Category & Product.xlsx**
   Category-wise and product-wise sales and performance analysis.

4. **Objective 3 — Order Status & Revenue Loss.xlsx**
   Analysis of order status, cancellations, returns, and potential revenue loss.

5. **Objective 4 — Payment, Fulfillment & Geography.xlsx**
   Analysis of payment methods, fulfillment types, and geographical performance.

The main objectives of this project are to:

* Understand Amazon sales performance.
* Identify high-performing products and categories.
* Analyze profit and revenue.
* Find revenue losses from unsuccessful orders.
* Understand customer payment preferences.
* Compare fulfillment methods.
* Analyze geographical sales performance.
* Present business insights through an easy-to-understand dashboard.
